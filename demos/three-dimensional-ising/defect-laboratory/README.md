# One Defect, Every Response

This standalone page uses the fixed-width `3×3×n` structured strip engine to
compare an unperturbed coupling set with a single local perturbation. It
returns the difference in all four single-handle Walsh responses at every
handle.

## Claim boundary

- `PROVED` in the underlying mathematical work: the relevant fixed-width
  spin-structure family has the stated 256-state separator carrier.
- `OBSERVED` here: browser floating-point response values, timings, and
  colour maps for user-selected couplings.
- `EXACT CHECK` in the local test suite: on small strips, shared, separate,
  and literal contractions agree in both the unperturbed and one-defect
  finite-field paths.

The page is not a material-design calculation, a thermodynamic-limit result,
or an exact solution of the three-dimensional Ising model.
