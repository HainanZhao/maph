# C88 selection: residual fractional-cover drop

Oracle selected the `CONJECTURED` invariant \(FD_k\): if an intersecting
six-partite residual \(G\) has \(\tau^*(G)\le k\), some vertex \(v\)
satisfies \(\tau^*(G\downarrow v)\le k-1\).  Iteration would give a
five-vertex cover only if its fractional premise is source-validated.

The first gate is the published 13-edge \(r=6\) equality control and every
residual through depth five.  Exact rational primal/dual certificates, not
floating LP output, decide each row.  One residual with no permitted drop
falsifies this mechanism only.  A finite pass authorizes continuation only
for a symbolic extreme-point reduction; it does not authorize a larger census.
