# C92 selection: common witness across two Zargar temperatures

`CONJECTURED` Oracle decision: select one source-admissible, finite falsifier
for a new Frankl mechanism.  For every labelled intersection-closed
\(\mathcal I\subseteq2^{[4]}\) containing \(\varnothing\), with
\(\bigcup\mathcal I=[4]\) and \(|\mathcal I|\ge2\), define
\[
 W_t(\mathcal I)=\left\{i\in[4]:
 \frac{\sum_{A\in\mathcal I:i\notin A}t^{|A|}}
      {\sum_{A\in\mathcal I}t^{|A|}}\ge\frac12\right\}.
\]
The sole proposed implication is
\(W_{1/3}(\mathcal I)\cap W_1(\mathcal I)\ne\varnothing\).

Oracle first questioned whether Zargar's low-temperature theorem determines a
common witness with the uniform endpoint.  It does not state that.  It then
questioned the appeal of continuity: weights can vary continuously while the
identity of a witness switches.  Hence this is deliberately a strong
mechanism with a high-information negative outcome, not a theorem-shaped
finite census.

Two independent exact routes are required: literal enumeration of all
\(2^{16}\) family masks with direct pairwise-intersection closure, and a
closure-generated canonical-family enumeration.  They must reconcile the
retained family count, deterministic hash, and every two-bit endpoint witness
mask.  A row with disjoint masks refutes only the common-witness mechanism.
A row with \(W_{1/3}=\varnothing\) is a source/convention error; a row with
\(W_1=\varnothing\) is a finite uniform-Frankl anomaly and must be preserved
separately, never folded into an ordinary crossing.

The primary rejected LRC candidate has no k=13-compatible source-defined
invariant; poset still risks Gold/Peczarski overlap; Ryser has no new state
space after C91.  The strongest flaw in the selected gate is that a complete
four-coordinate pass supplies neither a theorem nor a reason to enumerate
five coordinates.  If it passes, C92 has one short proof cap only for a
source-clear algebraic lemma forcing endpoint witness intersection; otherwise
it seals/pivots.  It never changes the temperature or control class.
