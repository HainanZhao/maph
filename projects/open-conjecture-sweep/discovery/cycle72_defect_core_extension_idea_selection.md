# C72 creative selection: global completion of the D=5 core

Candidate A — exact core-extension closure. Reconstruct the satisfiable
11-edge equality core as a six-partite hypergraph, enumerate the admissible
new lines that preserve exactly five excess pair intersections, and seek a
five-cover invariant that survives every admissible completion. Falsifier: a
completion with certified \(\tau\ge6\), which is a Ryser counterexample.

Candidate B — homological partition-lattice invariant. Encode the six
equivalence relations as a nerve and seek a cohomological obstruction to a
six-block cover. Falsifier: the D=5 core's nerve already has the target class
while its cover number is five.

Candidate C — direct minimal-counterexample SAT. Search full labelled
6-partite hypergraphs near the core without fixing the defect. Falsifier: a
certified \(\tau\ge6\) instance; bounded UNSAT has no universal meaning.

Question the questioning: B has no theorem connecting its prospective class
to the cover number; C abandons the only proved structure. Choose A, which
asks a finite, exact extension question forced by the C71 equality boundary.
It can either yield a counterexample or show precisely why the local core does
not globalize. B is the rejected alternative because it lacks a falsifier
that distinguishes a proof mechanism from decoration.
