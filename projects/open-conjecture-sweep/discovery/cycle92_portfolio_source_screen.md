# C92 portfolio source screen

This is pre-execution discovery, not a claim that any target is newly open or
novel beyond the sources below.

`PROVED` source scope for LRC: Sungkawichai--Trakulthongchai,
[*Eleven, twelve, and thirteen lonely runners* (2026), Theorem 1.3]
(https://arxiv.org/abs/2604.23906), proves \(LRC(k)\) through \(k=12\).
Their notation explicitly calls \(LRC(k)\) the \(k+1\)-runner case.  Hence
the program's \(LRC(13)\) target remains outside that theorem.  Its
eventual-properness proposition requires \(k+1\) prime, whereas \(13+1=14\);
C84 already refuted the verbatim \(\mathbb Z_{14}\) target-box extension.
Any LRC re-entry must use the new intermediate-sieve/finite-verification
interface, not C50's p=199 local engine or C84's composite lemma.

`PROVED` source scope for Frankl: Zargar,
[*The union-closed sets conjecture for non-uniform distributions* (2023),
Theorem 1.2 and Corollary 1.4](https://arxiv.org/abs/2305.19338), supplies a
half-frequency witness at the discrete low-temperature weights
\(t=m/k\le1/\sqrt{k}\), with \(k\ge5\).  It explicitly identifies ordinary
Frankl as the unweighted endpoint \(t=1\), which it does not prove.  This is
not Bouchard's irreducible-deletion framework (rejected before C91) and not
C86's all-inclusion Hall transport.

`OBSERVED` eligibility context: current primary-source screens retain the
1/3--2/3 conjecture and intersecting Ryser at \(r=6\).  C91 now excludes only
the reciprocal deletion-cover trace axiom; no variation of that axiom is a
C92 candidate.  C83/C84/C85/C86/C87/C88/C89/C90 exclusions remain in force.

## Independent mechanisms for Oracle comparison

1. **Frankl common-witness temperature continuation.**  Use the dual,
   intersection-closed convention from Zargar.  For \(\mathcal I\subseteq
   2^{[n]}\), freeze \(t_0=1/3\), the \(m=3,k=9\) instance of Corollary 1.4,
   and define \(f_i(t)=\sum_{A\in\mathcal I:i\notin A}t^{|A|}/
   \sum_{A\in\mathcal I}t^{|A|}\).  Ask whether one element can witness
   \(f_i(t_0)\ge1/2\) and \(f_i(1)\ge1/2\) simultaneously.  At \(t=1\) this
   is exactly the dual uniform Frankl endpoint.  A direct exact finite-family
   control is all \(2^{16}\) labelled subfamilies of \(2^{[4]}\), retaining
   exactly the nonempty intersection-closed families that contain
   \(\varnothing\), including dummy-coordinate rows.  It can enumerate the
   two rational inequalities and
   either produce a crossing-witness counterexample or establish only this
   control.  A crossing means the two witness sets have empty intersection;
   it is a clean falsifier of the continuation mechanism.  A pass matters only
   if it leads to a source-clear monotonicity lemma.  It does not assert that
   Zargar's theorem alone supplies a common witness.
2. **LRC intermediate-sieve projection certificate.**  Extract one exact
   projection/lift invariant from the 2026 source that is meaningful for
   \(k=13\) despite \(k+1=14\), then test it on a source-defined small
   congruence control.  It is distinct only if it avoids both the C84
   target-box predicate and C50 local p=199 enumeration.  At present its
   exact k=13 bridge is not yet specified, so source audit is the first gate.
3. **Poset separator ratio.**  A separator-to-log-concavity extension-ratio
   inequality remains distinct from C83's majority-cycle local fibers, but
   it must clear the Gold/Peczarski certificate vocabulary before any test.
4. **Ryser global dual completion.**  A C72-driven dual construction would
   need a new exact state space beyond C87/C88/C91 cover families.  No such
   state space is currently specified, so it is not executable.

The primary ranking is Frankl (specified exact falsifier, moderate cost), LRC
(high potential but no k=13 interface yet), poset (high overlap risk), then
Ryser (underspecified).  The strongest flaw in the Frankl choice is that a
shared witness at \(t=1/3\) and \(t=1\) may be too strong and irrelevant to
the endpoint theorem; that is exactly why one small crossing control is
valuable and cannot justify a census or repaired temperature value.
