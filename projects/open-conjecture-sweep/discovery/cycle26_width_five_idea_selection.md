# Cycle 26 idea selection scratch

Candidate A — **compact width-five transferred-weight control (chosen).**
Recover Cycle 22's independently proved base-4/leaf-952 width-four deficit
from the direct masks and its 176-point integer weight.  Then, without
learning a new weight, apply that weight to every Cycle-25 survivor in the
single deterministic 5+4+4 partition whose size-five block contains the five
most restricted coordinates.  This changes the capacity geometry while
keeping the proof interface exact and cheap enough for complete survivor
breadth.

Candidate B — a general width-five class-weight LP.  Rejected for now: its
large option family would confound a new geometry with a new floating dual,
and it has no validated width-five implementation control.

Candidate C — another cyclotomic character refinement.  Rejected: Cycle 25
showed the cheapest character split inherits the Cycle-24 class collapse;
another refinement is lower-information than changing geometry.

Questioning the choice: recovering a width-four certificate only validates
the inherited mask/weight interface, not the new width-five partition.  The
one restriction-selected partition can miss an incompatibility centered on
other coordinates.  It is still chosen because it is a full 60-leaf,
falsifiable transfer sweep and exposes whether the known witness has any
width-five robustness before an expensive fresh-weight LP is justified.

Chosen question: does the exact Cycle-22 weight produce a fresh direct
capacity deficit on a Cycle-25 survivor in the frozen 5+4+4 family?  Main
rejected alternative: a general width-five LP.  Falsifier: failure to replay
the Cycle-22 certificate, any direct-mask/partition mismatch, or no strict
deficit in the complete frozen family.
