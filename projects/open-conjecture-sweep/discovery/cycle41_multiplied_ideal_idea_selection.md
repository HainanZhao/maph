# Cycle 41 idea selection: first multiplied ownership-ideal layer

## Brainstorm

1. Multiply every rank-two ownership blocker by one ownership literal and
   solve the full rational degree-three moment system.
2. Search directly for a global Čech/cohomological obstruction to gluing the
   local signed moments.
3. Attempt a recursive theorem extending the Cycle 40 countermodel to every
   finite degree.
4. Return to a larger deterministic or randomized routing family.

## Decision questions

- For 1: does the integral singleton solution from Cycle 40 extend to triple
  tensors supported away from every pair-blocked owner diagonal, while also
  killing each genuine rank-three blocker?
- For 2: what proved map would carry a nonzero cohomology class back to the
  labeled ownership/direct-cover problem?
- For 3: is there a canonical extension operator in the current construction,
  rather than merely local solvability through degree three?
- For 4: can any routing family see information absent from the explicit
  signed countermodel?

## Questioning the questioning

The apparent question “should we try degree four?” is misleading: the first
missing information already has degree three. Cycle 40 kills unmultiplied
rank-three diagonals but does not multiply rank-two equations by a third
literal. Testing that omitted ideal layer is more discriminating than raising
the raw blocker rank.

A full degree-three linear system also starts too large. Cycle 40's sparse
solution is integral: every complete time type has one selected owner. If
that map avoids every rank-two blocked diagonal, all multiplied rank-two
relations hold for the delta triple outside genuine rank-three corrections.
The smallest prototype is therefore a constrained local completion test at
the realized rank-three blocker tuples. Only if this explicit witness fails
do we pay for general pair/triple marginals.

The cohomology route is rejected for now because it lacks a bridge theorem;
the extension theorem is rejected until an actual canonical extension rule
appears. More routing is rejected because Cycle 40 already supplies a broader
signed countermodel.

## Choice and falsifier

Choose the Boolean-reduced one-literal multiples of all rank-two blockers.
First test the integral Cycle 40 witness by exact allowed-cell tensor
completion, quotienting only after raw labels prove the class invariants.
If it fails, preserve the local obstruction and proceed within the same cycle
to the general exact degree-three system; candidate failure is not global
infeasibility.

Falsifier: a missing multiplier class, incorrect one-hot reduction, a selected
owner on a rank-two blocked diagonal, a quotient/raw mismatch, a tensor with
wrong pair marginals, or a nonzero multiplied blocker invalidates the affected
claim.
