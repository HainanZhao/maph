# SIC--Stark research cycle 73: exact CM reinduction

For each dimension-eight quartic packet and for each of the imaginary
quadratic bases

\[
M_6=\mathbf Q(\sqrt{-6}),\qquad
M_{30}=\mathbf Q(\sqrt{-30}),
\]

the finite group audit enumerates every \(\mu_4\)-valued one-dimensional
character of the relevant index-two subgroup.  Exactly two conjugate
characters induce the original two-dimensional character.

The induced character values agree on all sixteen elements of the normal
closure group.  This proves *linear* Artin equivalence.  There is no
remaining scalar twist, so equality of the associated Artin
\(L\)-functions, including local factors, follows formally.

This is stronger than the earlier projective \(V_4\) gate and is the
first decisive new fact of the ten-cycle pass.
