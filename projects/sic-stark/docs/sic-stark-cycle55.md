# SIC--Stark research cycle 55: both shifts and discriminant-32 transport

## Canonical shifts

For \(d=d_j=7\), \(r=1\), the twist congruence is

\[
\det(G)(2\lambda+13)\equiv1\pmod7.
\]

Hence:

\[
\lambda=1,\ G=I;\qquad
\lambda=0,\ G=\operatorname{diag}(1,-1).
\]

Both satisfy the coprimality condition
\(\gcd(2\lambda+6,7)=1\), and both reconstructed matrices pass the
idempotency and minor audits below \(4.8\cdot10^{-10}\).

This is numerical confirmation that both \(0\) and \(1\) are shifts for the
canonical tuple.  Exact status still follows the minor certificate.

## Form transport

The order of discriminant \(32\) has ordinary class number one.  Its
fundamental order unit has positive norm, so the proper form class number is
two; the two proper classes merge under determinant-minus-one
\(\mathrm{GL}_2(\mathbb Z)\)-equivalence.

Consequently every primitive form of discriminant \(32\) is
\(\mathrm{GL}_2(\mathbb Z)\)-equivalent to the canonical form.  AFK's
transformation formulas transport the shift identity across this single
improper class.  Once the canonical exact certificate is completed, no
second discriminant-32 TCC calculation is required.
