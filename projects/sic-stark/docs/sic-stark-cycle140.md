# SIC--Stark research cycle 140: line-bundle correction

Date: 2026-07-28

The antiperiodization

\[
 P_-(f)(x)=\sum_k(-1)^k f(x+kT)
\]

has half-integral Fourier characters.  Poisson summation shifts the
dual lattice from \(\mathbb Z\) to \(\mathbb Z+\tfrac12\); it does not
attach \((-1)^k\) to the dual alias index.

Therefore AFK wrap holonomy does **not** change the bilateral argument
from \(-q\) to \(q\).  This correction rules out a tempting but invalid
one-line application of Bailey's product summation.
