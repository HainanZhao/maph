# SIC--Stark research cycle 87: radical compression

Let
\[
x^2=u_0,\qquad
d^2=\sqrt{u_1/u_0},\qquad a=xd.
\]
The complete signed overlap table uses only
\[
\pm1,\quad \pm x^2,\quad \pm x^{-2},\quad
\pm d,\quad \pm d^{-1},\quad
\pm a,\quad \pm a^{-1}.
\]
The distinguished root \(x=1.700015775\ldots\) satisfies
\[
x^8-2x^6-2x^4-2x^2+1=0.
\]
Moreover \(d=1.598965898\ldots\), and its square is an explicit
polynomial in \(x\):
\[
d^2=\frac{3x^7-2x^6-5x^5+4x^4-7x^3+4x^2-9x+6}{2}.
\]
This reduces the exact table from a general ray-field computation to
a small radical algebra.
