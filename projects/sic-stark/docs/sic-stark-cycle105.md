# SIC--Stark research cycle 105: special-Gamma theorem coverage

Date: 2026-07-28

## Question

Can an existing theorem on Barnes multiple-gamma values make the
dimension-six double-sine value algebraic directly?

## Closest theorem

Barquero-Sanchez, Masri, and Tsai give an effective expression for Stark
units in **real quadratic extensions** of totally real fields by Barnes
multiple-gamma values
([Research in Number Theory 7 (2021), 38](https://doi.org/10.1007/s40993-021-00268-8)).

For the dimension-six ray group \(C_6\), that theorem reaches the
quadratic character \(\chi_3\).  This is exactly the lower component
already evaluated in the project:

\[
 L'_S(0,\chi_3)=2\log Y.
\]

It does not reach the faithful characters \(\chi_1,\chi_5\), whose fixed
field extensions over \(K\) have degree six.  Passing to the quadratic
subextension replaces the faithful character by \(\chi_3\) and loses the
primitive cubic direction.

## Result

\[
\boxed{\text{the special-Gamma theorem proves the known quadratic
stratum, not the faithful sextic stratum.}}
\]

This independently confirms the conductor and character decomposition:
the new theorem needed for dimension six is genuinely cyclic-sextic,
not merely a more explicit implementation of a quadratic Barnes-gamma
formula.
