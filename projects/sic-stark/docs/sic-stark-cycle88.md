# SIC--Stark research cycle 88: shared-subfield gluing

An exact certificate cannot treat the overlap field and
\(\mathbb Q(\zeta_{16})\) as linearly disjoint.  The first shared
element is
\[
\sqrt2=\frac{-x^7+x^5+5x^3+3x}{2}
       =\zeta_{16}^2-\zeta_{16}^6.
\]
There is a second component-selection identity:
\[
d=(\zeta_{16}-\zeta_{16}^7)
\left(
\frac{x^7-x^6-x^5}{2}+x^4-2x^3+x^2-2x+\frac32
\right).
\]
Both identities were discovered by forcing exact reduction rather than
accepting a numerical near-zero.  They select the component containing
the positive AFK roots and make the quotient-ring representation
canonical.
