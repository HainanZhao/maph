# SIC--Stark research cycle 90: form-class scope

Dimension eight has two discriminants because the admissible conductor
divides three:
\[
\Delta=5\quad\text{or}\quad\Delta=45.
\]
The discriminant-five order is maximal and has narrow class number one:
the ordinary class number is one and \(\phi\) has norm \(-1\).
Consequently every discriminant-five admissible form is transported
from \(\langle1,-3,1\rangle\) by AFK's \(\mathrm{GL}_2(\mathbb Z)\)
covariance.

The discriminant-45 stratum was closed separately in cycles 72--81 and
has ring class number one.  AFK's formal TCC does not demand transport
between different discriminants; it demands equality of shift sets
within a discriminant.  The two independent closures therefore cover
all dimension-eight admissible tuples once both analytic bridges are
fully certified.
