# Scope audit: what the five controls actually control

The five selected Engine-C packets are quartic in the character sense,
and each proof uses a cyclic-quartic extension over an imaginary
quadratic CM base. Roblot's index-formula setup cannot be imported
merely from that fact: the proposed Roblot coefficient must be
constructed on the original cyclic-quartic subextension over the real
quadratic base and its hypotheses checked there.

The existing Engine-C route provides:

1. a selected quartic CM character;
2. a certified complex \(L'(0,\psi)\);
3. exact unit-lattice isolation after Stark's proved
   imaginary-quadratic theorem;
4. an exact Fourier-to-positive-norm bridge.

It does not provide a separately constructed Roblot-canonical weak
unit for the original real-quadratic extension. Consequently the
available logarithmic comparison vector is mathematically valid for
the Engine-C proof but statistically dependent on the same
\(L'\)-value. It cannot be used as an independent response variable
when fitting a new phase law.

This distinction blocks fitting but does not waste the controls. The
two-route cases are strong convention tests: distinct imaginary bases
and character data must produce the identical original packet phase.
