# B3 input preregistration amendment v1: the finite set in A3

Frozen: 2026-07-31 UTC, after the first population pilot exposed a
tower-embedding ambiguity and before any kernel received an
eligibility verdict.

## Preserved preliminary failure

The initial `screen_b3_roblot_kernel.gp` pilot tried to transport the
finite part of the primitive conductor through an absolute
\(k\subset K^+\subset K\) tower.  The first row, RQ-000030, produced
two conjugate quadratic factors for \(K^+/k\).  The script rejected
the row before printing A1, A2, A3, or an eligibility result.

That attempt exposed a more basic convention error in the original B3
preregistration: Roblot's A3 concerns every finite prime in the chosen
set \(S\), which for this census calculation is the support of the
original frozen finite modulus, not merely the primitive character
conductor.  The original document is preserved; this amendment
controls A3.

## Corrected exact A3 check

For each prime \(\mathfrak q\) of \(k\) dividing the original frozen
finite ideal:

1. if \(\mathfrak q\) divides the primitive conductor, record it as
   ramified;
2. otherwise evaluate the primitive quartic character exactly on
   \(\mathfrak q\) and require its value to have order \(2\) or \(4\),
   not order \(1\).

This is equivalent to A3.  Under A1, complex conjugation is the unique
order-two element \(\tau\) of \(G\simeq C_4\), and
\(K^+=K^{\langle\tau\rangle}\).  A ramified prime has nontrivial
inertia in \(C_4\), hence its inertia contains \(\tau\).  At an
unramified prime the decomposition group is generated by Frobenius;
its intersection with \(\langle\tau\rangle\) is nontrivial exactly
when the quartic character value has order \(2\) or \(4\).  In either
case every prime above \(\mathfrak q\) is ramified or inert in
\(K/K^+\); character value \(1\) is exactly the split failure.

The exact local rows must record the prime norm, valuation in the
original modulus, valuation in the primitive conductor, and (when
unramified) the Frobenius-character order.  No floating-point or
absolute-field embedding choice enters this gate.
