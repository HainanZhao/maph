# Cycle 013 — independent imaginary-side reconstruction

Starting separately from each Route-1 candidate, `rnfconductor`
derives its conductor and a full ray-field reconstruction:

- \(\mathbb Q(i)\), conductor \((7)\), ray group \(C_{12}\);
- \(\mathbb Q(\sqrt{-7})\), conductor
  \(\mathfrak p_2^2\bar{\mathfrak p}_2^2\mathfrak p_7\), ray group
  \(C_6\times C_2\).

Both full ray fields are isomorphic to the K-side normal closure.
This dual agreement is stronger than a unique-base result. The
\(\mathbb Q(i)\) route is selected for the printed table solely because
it has 2 divisors rather than 18.
