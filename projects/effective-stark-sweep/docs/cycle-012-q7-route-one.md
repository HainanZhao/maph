# Cycle 012 — commutator-fixed route

\(\left(\begin{smallmatrix}1&3\\0&1\end{smallmatrix}\right)\), and
the commutator-fixed absolute field is
\[
x^{12}-x^{10}+x^8-x^6+x^4-x^2+1.
\]

quadratic candidates: \(\mathbb Q(i)\) and
\(\mathbb Q(\sqrt{-7})\). The failed uniqueness transcript is
