# Cycle 2: five-lane algebraic compression screen

## Decision question

Does any one of five independent local or collective mechanisms survive a
first exact falsification test while offering commuting transfer operators,
polynomially many sectors, bounded/subexponential auxiliaries, exact recursive
closure, or a controlled thermodynamic calculation?

## Question the questioning

`PROVED`: Stage 1 excludes only uncompressed surface spin-structure sums,
ordinary ordering-based free fermions, and scalar self-duality in their stated
forms. It does not license treating a determinant, gauge field, tetrahedron
equation, matchgate, or block tensor as progress merely because that language
is sophisticated. The test in each lane therefore targets the first algebraic
condition that would create an actual reduction.

## Brainstorm and lane independence

- Lane A changes the local operator algebra and asks for tetrahedral
  consistency/commuting layers.
- Lane B keeps the exact surface formula but treats the spin-structure
  dependence as a Boolean function to be collectively compressed.
- Lane C changes statistics locally and pays with higher-form gauge
  constraints; it must explicitly discharge the flux-sector sum.
- Lane D keeps the high-temperature tensor network and asks whether local
  basis changes place all required tensors, including crossings, in a
  contractible Gaussian class.
- Lane E integrates degrees of freedom exactly and asks whether induced
  interactions close under a finite coordinate system.

These are different mechanisms: a failure in one supplies no inference about
the others.

No winner is selected in this note. Selection is permitted only after every
row has produced its declared exact result.
