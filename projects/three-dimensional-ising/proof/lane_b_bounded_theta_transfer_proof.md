# Bounded relative-theta transfer for the minimum-genus `L x 3 x 3` family

## Claim boundary

`PROVED`: for every free box `G_L=P_L square P_3 square P_3`, `L>=4`, the
period-two rotation generated by `src/lane_b_recursive_family.py` is a
minimum-genus cellular embedding.  In nested relative-homology coordinates,
the complete tensor of `4^(L-1)` Walsh values, and hence the complete tensor
of quadratic-refinement values `F(q)`, has tensor-train rank at most `1024`
when each two-bit handle is one four-state site.  If every handle is split
into two binary sites, the uniform TT-rank bound is `2048`.  The
representation is exact for arbitrary edge weights.

This is a uniform collective compression for a fixed `3 x 3` transverse
section.  It does not bound ranks when both transverse dimensions grow and
does not by itself control the three-dimensional thermodynamic limit.

## 1. Minimum-genus period-two rotation

Write `R_L` for `recursive_rotation(L)`.  Its definition starts from the
pinned `R_4` and alternates two finite local extension tables, `A->B` and
`B->A`.  Deleting the new slice recovers `R_L` exactly up to cyclic rotation
at each vertex.

The two local dart checks have the same face surgery:

1. all but two old faces are retained;
2. the removed faces have lengths `4` and `2L+4`;
3. eleven new quadrilateral faces and one face of length `2L+6` appear.

The two extension tables exhaust the parity cases.  Induction from `R_4`
therefore gives

```
V_L = 9L,
E_L = 21L-9,
F_L = 10L-5,
face lengths = 4 repeated (10L-6) times, and 2L+6 once,
genus(R_L) = L-1.
```

Millichap--Salinas (2022), Theorem 4, proves
`gamma(G(alpha,2,2))=alpha`.  Their path `P_alpha` has `alpha+1` vertices, so
`G_L` is their `G(L-1,2,2)`.  Hence the displayed embedding is minimum genus,
not merely an upper-bound construction.  The exact hypothesis audit is in
`discovery/cycle4-grid-genus-source-audit.md`.

## 2. Nested relative homology

Let `H_L` denote the `2(L-1)`-dimensional mod-two homology of `R_L`.  Start
with the pinned coordinates on `H_4`.  At each extension introduce a pair
`(a_i,b_i)` and use the adapted defect coordinate as `a_i`.  The exact two
local checks give an orthogonal symplectic decomposition

```
H_(L+1) = H_L orthogonal-direct-sum <a_L,b_L>,
<a_L,b_L> = 1.
```

The old facial-boundary space has a one-dimensional image generated by
`a_L`; equivalently, the old sectors must be refined by one relative bit.
The label update is local:

- two edges in the former terminal slice acquire `a_L`;
- all nine longitudinal edges have label zero;
- among the twelve new transverse edges, 13 of all 21 added edges have label
  zero, two have `b_(L-1)`, two have `b_(L-1)+a_L`, and four have `b_L`.

The choice of the two corrected transverse edges alternates with period two.
After the following extension, this makes a bulk slice depend only on

```
b_(i-1), a_i, b_i, a_(i+1).
```

All unaffected faces inherit label zero.  In each of the two local tables,
the eleven new squares and the new long face also have label zero.  The old
intersection form is unchanged and `(a_i,b_i)` is an orthogonal symplectic
pair.  These finite local statements prove the label recurrence by induction.

## 3. Exact character-transfer identity

For `mu in H_L^*`, define the full Walsh tensor

```
G_L(mu) = sum over A subset E_L, partial A=0 of
          (-1)^mu(ell_L(A)) product over e in A of t_e.
```

Split `A` into a transverse subset `S_i` of the twelve edges in slice `i`
and a longitudinal subset `X_(i+1)` of the nine edges to the next slice.
Let

```
P = {x in F_2^9 : popcount(x) is even}.
```

Thus `|P|=256`.  Put `X_0=X_L=0`.  At slice `i`, evenness is exactly

```
partial_perp S_i = X_i + X_(i+1).
```

For `x,y in P`, define the explicit `256 x 256` matrix

```
M_i(mu)[x,y]
  = sum over S subset E_perp(i), partial_perp S=x+y of
      (-1)^mu(ell_L(S)+ell_L(X_(i+1)=y))
      product over e in S union X_(i+1)(y) of t_e.
```

The longitudinal labels in this family are zero, but they are retained in the
formula to make the allocation convention unambiguous.  Every edge is used
once and the displayed parity equation is equivalent to `partial A=0`.
Therefore, coefficient by coefficient in the multivariate edge weights,

```
G_L(mu) = e_0^T M_0(mu) M_1(mu) ... M_(L-1)(mu) e_0.       (1)
```

This is an identity, not an asymptotic approximation or numerical tensor
factorization.

## 4. Uniform TT-rank bound

Outside the fixed initial and terminal tensors, `M_i` depends only on

```
mu[b_(i-1)], mu[a_i], mu[b_i], mu[a_(i+1)].
```

Cut the character variables between handles `k` and `k+1`.  Only `M_k` and
`M_(k+1)` straddle the cut.  Expand them using the two possible values of the
right bit `mu[a_(k+1)]` and the two possible values of the left bit
`mu[b_k]`.  Cutting the matrix product in (1) also exposes one parity state
`x in P`.  Consequently the flattening is a sum of at most

```
2 * 2 * |P| = 1024
```

outer products.  Every flattening between complete handle sites is therefore
at most `1024`, independently of `L`.

For one symplectic handle, the map from sector values to quadratic-refinement
values has kernel

```
K[lambda,(a,b)] = (-1)^(a*b + lambda_a*a + lambda_b*b).
```

It is a signed `4 x 4` Hadamard matrix and satisfies `K K^T=4I`.  The full
map is a tensor product of these local invertible kernels (with one fixed
six-bit prefix gauge).  Invertible transformations internal to each tensor
site preserve every handle-cut flattening rank.  Hence the same uniform
handle-site bound `1024` holds for the complete `F(q)` tensor.  Splitting a
four-state TT core into two binary physical sites introduces an intermediate
rank of at most twice either adjacent rank.  Thus the corresponding
binary-coordinate TT has the uniform bound `2048`, including cuts inside a
handle.

Direct storage takes `4^(L-1)` polynomial entries.  A TT realization of the
proved bound takes `O(L)` cores of bounded size.  With translation-invariant
anisotropic weights, the two bulk cores repeat with period two.

## 5. What would refute or limit the theorem

- A mismatch in either local dart/label table refutes the induction.
- A handle-cut rank above `1024`, or a binary-site TT rank above `2048`,
  refutes the corresponding rank theorem.
- The theorem says nothing about a family `L x M x N` with growing `M,N`;
  using it as a full 3D thermodynamic compression would exceed its scope.
