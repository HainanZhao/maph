# Cycle 11 v2 addendum: alternative rotations of one cubic grid graph

Cycle 11 v1 established the robustness class and used two cellular rotations
of `K_(3,3)` as the sharp arbitrary-rotation obstruction.  This addendum
closes the goal checklist's narrower request for alternative rotations of the
same cubic grid graph.

`PROVED`: the cube graph `P_2 square P_2 square P_2` has orientable cellular
rotations of genera zero and two.  Its complete pre-Arf sector count therefore
changes from one to sixteen.  Exhaustion of all 256 binary local-orientation
choices gives the genus census `2,54,200` at genera `0,1,2`.

`CERTIFIED_NUMERICAL`: at the frozen nonuniform edge specialization, the
normalized Arf contractions for the selected genus-zero and genus-two
rotations agree with direct even-subgraph enumeration over two primes.

This addendum changes no Cycle 11 v1 claim.  It strengthens the negative side
from “the same abstract graph” to “the same cubic grid graph” and supplies an
explicit nonminimum-genus cellular grid embedding.
