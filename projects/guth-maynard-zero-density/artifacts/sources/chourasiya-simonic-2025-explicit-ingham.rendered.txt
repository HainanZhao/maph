AN EXPLICIT FORM OF INGHAM’S ZERO DENSITY ESTIMATE

SHASHI CHOURASIYA AND ALEKSANDER SIMONIˇC

Abstract. Ingham (1940) proved that N(σ, T) ≪ T 3(1−σ)/(2−σ) log5 T, where N(σ, T) counts the
number of the non-trivial zeros ρ of the Riemann zeta-function with ℜ{ρ} ≥ σ ≥ 1/2 and 0 < ℑ{ρ} ≤ T.
We provide an explicit version of this result with the exponent (7−5σ)/(2−σ) of the logarithmic factor.
In addition, we also provide an explicit estimate with asymptotically correct main term for the fourth
power moment of the Riemann zeta-function on the critical line.

1. Introduction

Let ζ(s) be the Riemann zeta-function and let ρ = β + iγ be its non-trivial zero, that is, ζ(ρ) = 0
with 0 ≤ β ≤ 1 and γ ∈ R. Let N(T) be the number (counted with multiplicities) of all non-trivial
zeros with 0 < γ ≤ T, while for σ ≥ 0 and T > 0 define N(σ, T) := # {ρ: ζ(ρ) = 0, β ≥ σ, 0 < γ ≤ T},
where the zeros are again counted with multiplicities. Trivially, the function N(σ, T) is decreasing in σ
and increasing in T, N(σ, T) ≤ N(T) ∼

ourselves to the range of 1/2 ≤ σ ≤ 1 and T ≥ HRH throughout this paper.
