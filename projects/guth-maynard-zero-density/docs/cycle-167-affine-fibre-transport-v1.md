# Cycle 167: exact affine-fibre cross-label transport classifier

## Claim boundary

`PROVED`: within the **one-step reduced-rational affine multiplicative
architecture** below, the only beta-preserving approximant map is exactly
classified.
For a retained affine fibre it either produces a labelled cross-label strip
edge satisfying explicit residue, range, and balance conditions, or the first
failed one is an exact labelled obstruction.

This theorem does not say that a Cycle-166 massed web has an eligible anchor.
It proves no target-local Cycle-67 packet, transport recurrence, E7/E9
skeleton, census bound, density gain, or prime-interval consequence.

## Architecture and rigidity

Let `qE=a+e`, where `a,q` are positive coprime integers.  Suppose a source
strip row has `y=1+alpha_ell` and its target has `y^+=Ey`.  Restrict to the
reduced rational approximant ansatz, linear in the old integer row coordinate,

```text
h^+=B h,             j^+=j+A h,                    (1)
```

that keeps the same beta and uses the frozen rational multiplier
`B=q/a`.  Cancellation of the remaining constant coefficient then forces
`A=1-q/a`; equivalently, the whole leading term factors through the common
approximation error `e`.
Thus the reduced rational ansatz has, uniquely,

```text
B=q/a,              A=1-q/a.                       (2)
```

Thus an integral row can use this map precisely when `a|h`; then

```text
h^+=qh/a,           j^+=j+h-h^+.                   (3)
```

With an arbitrary real multiplier, exact cancellation would instead choose
`B=1/E`; that possibility lies outside the frozen rational approximant
architecture. There is likewise no claim about nonlinear, multistep, or
loop-based maps.

## Affine fibre and exact eligibility

For the canonical Cycle-166 affine fibre `h=h0+r n`, `n in N`, the primitive
four-parent count obeys

```text
P(N) <= binom(|N|,4).                                (4)
```

So a parent count gives only a fourth-root lower bound on distinct parameters.
It cannot itself force a density in a residue class.

The integrality condition in (3) is

```text
r n = -h0 (mod a).                                   (5)
```

It is soluble iff `gcd(a,r)|h0`; if soluble, it is exactly one class modulo
`a/gcd(a,r)`.  With the Cycle-67 range `I=[H,2H]`, the complete eligible set
is therefore

```text
N_elig={n in N: (5), h0+r n in I, q(h0+r n)/a in I}. (6)
```

This is necessary and sufficient for a direct integral edge whose source and
target both lie in the frozen row range.

## Exact error and balance

Put `R=j+beta-h(y-1)`.  For every `n in N_elig`, (3) gives the exact identity

```text
j^+ + beta - h^+(y^+-1) = R - h*y*e/a.              (7)
```

If `|R|<=C0/X`, `|e|<=C1/(KX)`, `h<=2H`, and `y<=Y`, then the target strip
constant is at most

```text
C0 + 2*H*Y*C1/(aK).                                  (8)
```

Hence fitting the Cycle-67 enlarged budget `C0+C1` requires the explicitly
checked balance `2HY/(aK)<=1`; `qK<=H` does not imply it.

## Independence and remaining bridge

Finite exact models separately realize (i) a fibre missing its only
divisibility residue while both ranges are valid, and (ii) a fibre in which
every source row is divisible but every transformed row misses the range.
Together with an arbitrary large `H/(aK)` model, they show that no implication
from parent multiplicity alone to direct transport is available in this
architecture.

The direct map produces a genuine beta-preserving **cross-label edge**.  Since
`qE≈a` is not `q alpha_(ell+u)≈a`, the edge is not a Cycle-67 local packet.
The next bridge must join it to a target-local packet or use a closed labelled
transport loop to create such a relation.
