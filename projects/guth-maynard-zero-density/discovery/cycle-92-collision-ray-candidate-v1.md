# Cycle 92 discovery candidate: collision excess is a rational-ray web

`CONJECTURED` route: turn the Cycle-90 collision count into a bound-or-web
dichotomy before attempting a global discrepancy estimate.

approximate `exp(2pi a/D)` within `O(1/(KQ))`. Farey spacing is `Omega(Q^-2)`
and `K>>Q`, so the reduced fractions must coincide. All multiplicity at one
`a` therefore comes from integer multiples of one primitive ray. Since
`KQ>>D`, monotonic spacing of `exp(2pi a/D)` prevents the same ray from
serving two different `a` values.

carrying an injective primitive rational label of denominator `O(Q/M)`,
where `M` is its collision multiplicity.
